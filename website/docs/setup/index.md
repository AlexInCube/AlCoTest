# Setup

Host AICoTest on your own machine or server in three steps:

1. [Configure .env](./configure-env.md) with the bot settings.
2. Get the tokens for Discord and the optional music services, as [API Configure](./api-configure.md) describes.
3. Start the bot [in Docker](./docker.md). This is the recommended way.

If you want to change the bot's code, [run it locally](../development/run-locally.md) instead of in Docker.
